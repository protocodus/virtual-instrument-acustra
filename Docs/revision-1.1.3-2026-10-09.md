# Acustra 1.1.3 build 1

This revision contains the accepted October 9 sound choices. Original's
Auditorium close/mono contour reduces the played A2 emphasis. Classic retains
the selected fixed physical-string pluck direction, half-share Pick release,
full authored Thumb slip and gentle broad-loss sustain corner at 0.75 of the
preceding value. The latter is an intrinsic Classic string profile for every
technique, including sympathetic strings; Original's sustain is unchanged.

The measured body and bridge data, public physical calibration, parameter and
product identities, interface and existing release scheduling remain intact.
Output reference gains are fitted with the existing loudness, strum and Pick
headroom limits. Rejected stronger sustain and duller Pick candidates remain
historical experiments outside the production DSP.

The selected DSP snapshot passed all 76 suites and 12 affected canonical
checks. Its 221 reviewed non-Docs files and renderer matched the isolated
validated source. The final construction pack covers 144 combinations and
288 phrases; all 144 Original phrases match the preceding accepted-attack
checkpoint. See [the integration evidence](classic78-sustain-integration-2026-10-09.json)
and [construction evidence](classic78-final-sustain-construction-review-2026-10-09.json).
The user's Pick/Thumb listening choice covers the focused Auditorium/Mahogany
clips; broader engineering coverage does not imply an additional ear verdict.

The desktop build uses version 1.1.3, build number 1, and the stable
`cz.protocodus.acustra` identity. Its distribution directory is
`dist/1.1.3/build.1/macOS-universal/`. The Reason Rack Extension retains its
established version sequence as 1.2.2f1 and product `cz.protocodus.Acustra`,
pinning the same canonical source commit while preserving the Rack wrapper.

Desktop format, package, Rack contract, SDK and host validation results are
recorded beside the generated revision artifacts. Earlier DSP tests establish
the selected sound implementation; actual wrapper, binary and host checks
establish only the formats and host behavior exercised by this revision build.
